# رصد RASD — Arabic Threat Intelligence

منظومة لاكتشاف **حملات** الهندسة الاجتماعية والاحتيال باللغة العربية (فصحى ولهجات): تستخرج المؤشرات الرقمية من الرسائل، وتربطها في رسم أدلة، وتشرح سبب كل حكم وكل ربط. ليست مصنِّف رسائل.

> **حالة المشروع:** نموذج هندسي أولي (v0.1) يعمل ويُختبر. الأرقام أدناه مقاسة فعلًا، ومعظمها على بيانات اصطناعية — اقرأ قسم «ما الذي لم يثبت بعد».

## التشغيل

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[api,eval,dev]"

pytest                                   # 29 tests
rasd analyze "عزيزي العميل تم إيقاف بطاقتك حدث بياناتك https://alrajhi-update.example/login" --sender 0500012345
rasd seed --db rasd.db                   # synthetic demo data (.example/.test domains only)
RASD_DB=rasd.db RASD_API_KEYS=my-key:default rasd serve   # dashboard: http://127.0.0.1:8000  API docs: /docs
rasd eval --seed 7 --external data/external/Arabic_Spam.csv   # reproduces docs/eval/results_seed7.json
```

البيانات الحقيقية لا تُوزَّع مع المستودع (GPL‑3.0 وتحوي بيانات شخصية)؛ نزّلها إلى `data/external/Arabic_Spam.csv` من `github.com/KhalidAlsantali/Arabic-SMS-Spam-Data`.

المحرك الأساسي (`rasd.analysis`, `rasd.indicators`, `rasd.graph`, `rasd.xai`) بلا أي اعتمادية خارجية؛ FastAPI للـAPI و scikit-learn لخطوط المقارنة فقط.

## ما الذي يفعله

| المرحلة | المكوّن | الملف |
|---|---|---|
| تطبيع يحفظ مواضع النص الأصلي | `OffsetText` | `src/rasd/text.py` |
| العربية: طيّ إملائي، كشف التمويه، تحديد اللهجة، معجم الأساليب | حزمة لغة | `src/rasd/lang/arabic*.py` |
| استخراج المؤشرات (روابط، نطاقات، هواتف، آيبان، محافظ، حسابات) | `extract` | `src/rasd/indicators/` |
| تقييم جمعي شفاف + حواجز قرار | `score` | `src/rasd/analysis/` |
| ربط الحملات بمعيار أدلة صريح | `CampaignGraph` | `src/rasd/graph/engine.py` |
| تفسير الحكم والربط + الواقع المضاد | `explain` | `src/rasd/xai/` |
| خصوصية: تنقيح وتجهيل | `redact`, `pseudonymize` | `src/rasd/privacy.py` |
| API + تصدير STIX 2.1 | FastAPI | `src/rasd/api/`, `src/rasd/integrations/` |
| لوحة التحقيق | صفحة واحدة بلا اعتماديات | `src/rasd/dashboard/` |
| بيئة الاختبار والمقارنة | مولّد + مقاييس + خطوط مرجعية | `src/rasd/eval/` |

## النتائج المقاسة (البذرة 7؛ التفاصيل والحدود في `docs/04-evaluation.md`)

**بيانات حقيقية عامة** (نصف اختبار محجوب من 231 رسالة، صُنّف يدويًا بعد تجميد المحرك):

| | رصد | قائمة كلمات | مصنِّف TF‑IDF للـspam |
|---|---|---|---|
| احتيال واضح مُلتقَط (n=15) | 12 | 4 | 14 |
| احتيال محتمل مُلتقَط (n=5) | 0 | 0 | 4 |
| تسويق مشروع أُشير إليه خطأً (n=52) | 0 | 0 | 51 |
| رسائل عادية أُشير إليها خطأً (n=158) | 0 | 1 | 4 |

**بيانات اصطناعية بحقيقة حملات معروفة** (454 رسالة احتيالية، 36 حملة):

| ربط الحملات | دقة الأزواج | استدعاء الأزواج | F1 |
|---|---|---|---|
| رصد (رسم الأدلة) | 0.99 | 0.93 | 0.96 |
| تجميع بتشابه النص (أفضل عتبة، مضبوطة على الاختبار) | 0.54 | 0.51 | 0.53 |
| مطابقة حرفية للمؤشرات | 1.00 | 0.10 | 0.19 |
| رصد + السماح لتشابه النص بالدمج (ما يمنعه التصميم) | 0.22 | 0.97 | 0.36 |

## ما الذي لم يثبت بعد

- أرقام الكشف على البيانات الاصطناعية **حدّ أعلى**: القوالب والمعجم من تأليف الفريق نفسه.
- العيّنة الحقيقية صغيرة (20 رسالة احتيال)، بمصنِّف واحد غير خبير، من مصدر واحد سعودي.
- لا توجد بيانات عربية عامة بتسميات حملات؛ دقة الربط على حملات حقيقية **غير مقاسة**.
- لم تُجرَ مقارنة مع منتجات تجارية (لا يمكن تشغيلها هنا)؛ المقارنة مع **فئات التقنيات** فقط.
- العربيزي (العربية بحروف لاتينية)، الصور، والرسائل الصوتية خارج النطاق حاليًا.
- سجلّ العلامات الرسمية (`indicators/brands.py`) بذرة تحتاج تحققًا مع أصحابها قبل أي استخدام إنتاجي.
