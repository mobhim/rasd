# 3. المعمارية

## 3.1 مسار البيانات

```
رسالة (نص، مرسل، مستلم، قناة، وقت)
   │
   ▼
[1] تنظيف محايد لغويًا ── حذف الأحرف غير المرئية، NFKC، طيّ الأرقام الهندية      text.py
   │        (كل حرف يحتفظ بموضعه في النص الأصلي)
   ├──► [2] استخراج المؤشرات ── روابط/نطاقات/هواتف/آيبان/محافظ/حسابات          indicators/
   │            + تحليل معجمي للروابط (انتحال علامة، typosquat، استضافة مجانية…)
   ▼
[3] حزمة اللغة (قابلة للإضافة) ── طيّ إملائي، كشف التمويه، اللهجة، الأساليب      lang/
   ▼
[4] تجميع الأدلة + قواعد السياق ── «يذكر بنكًا والرابط لا يتبعه»…                analysis/pipeline.py
   ▼
[5] مقيِّم جمعي + حواجز قرار ── score = sigmoid(bias + Σ wᵢ)                     analysis/scorer.py
   ▼
[6] خصوصية ── تنقيح النص، تجهيل المستلم ──► تخزين (SQLite، متعدد المستأجرين)      privacy.py, storage.py
   ▼
[7] رسم الأدلة ── حملات، عائلات قوالب، سلاسل ربط                                graph/engine.py
   ▼
[8] التفسير ── أسباب، واقع مضاد، سرد الحملة                                     xai/
   ▼
API (REST + STIX 2.1)  ·  لوحة التحقيق  ·  CLI
```

المراحل 1–5 و7–8 حتمية، تعمل دون شبكة، وبلا اعتماديات خارجية.

## 3.2 أين يُستخدم الذكاء الاصطناعي وأين لا

| القرار | الآلية | لماذا |
|---|---|---|
| الحكم على الرسالة | مجموع أوزان أدلة مسمّاة | قابل للتدقيق؛ التفسير هو النموذج نفسه |
| قيم الأوزان | أولويات خبير؛ أو انحدار لوجستي على **الأدلة نفسها** (`eval/calibrate.py`) | تعلّم آلي حيث يفيد، مع بقاء القرار جمعًا شفافًا |
| ربط الحملات | اتحاد‑بحث على موارد مشتركة + معيار أدلة | الربط ادّعاء استخباراتي يجب أن يُعلَّل بمورد |
| تحديد اللهجة | علامات معجمية معلنة | شفاف؛ قابل للاستبدال بنموذج مدرَّب خلف الواجهة نفسها |
| نماذج لغوية/LLM | **اختيارية واستشارية فقط** عبر `Analyzer.advisors` | مساهمتها مسقوفة (±1 لوغاريتم أرجحية) ولا تستطيع وحدها إيصال الحكم إلى «احتيالية» — مفروض في المقيِّم ومُختبَر |

لا يوجد مزوّد LLM مضمَّن: لم نجد بعدُ قرارًا يحتاجه، وإضافته دون حاجة مقاسة مخالفة لقيود المشروع.

## 3.3 حواجز القرار (مستقلة عن الأوزان)

1. **لا إدانة بالأسلوب وحده:** «احتيالية» تتطلب ناقل ضرر (رابط/وسيلة تواصل/مستفيد) أو طلبًا صريحًا لبيانات سرية؛ وإلا يُسقَف الحكم عند «مشبوهة».
2. **الإشارة الاستشارية لا تُدين.**
3. **تكرار الكلمة لا يراكم الوزن:** دليل واحد لكل قاعدة.

## 3.4 حزمة اللغة — نقطة التوسّع

`LanguagePack` (`lang/base.py`) تعرّف: `affinity` · `fold` · `fold_term` · `tactic_patterns` · `variety`. تصنيف الأساليب (`urgency`, `threat`, `credential_request`…) محايد لغويًا؛ الحزمة تربط الصيغ السطحية به. إضافة لغة = ملف حزمة واحد + أسماء العلامات بتلك اللغة؛ لا تغيير في المسار أو المقيِّم أو الرسم أو الـAPI. اختبار `test_new_language_plugs_in_without_touching_the_pipeline` يسجّل حزمة تركية وهمية وقت التشغيل ويثبت ذلك. الحزمة الإنجليزية المرفقة صغيرة عمدًا وليست جزءًا من أي ادّعاء أداء.

**الحزمة العربية:** طيّ الهمزات والتاء المربوطة والألف المقصورة؛ حذف التشكيل والتطويل؛ ضمّ الأحرف المفكّكة («ع ا ج ل»)؛ ردّ الحروف الفارسية/الأردية الشبيهة؛ معجم أساليب بالفصحى والخليجية والمصرية والشامية والمغاربية والعراقية يُطوى بالقواعد نفسها ويراعي السوابق والضمائر المتصلة.

## 3.5 معيار الأدلة في ربط الحملات

| الفئة | الإشارات | القاعدة |
|---|---|---|
| **قوي** — مورد يجب أن يسيطر عليه المهاجم ليُتواصَل معه أو يقبض | نطاق مسجَّل، مسار رابط مختصر، رقم تواصل في المتن، آيبان، محفظة، حساب تليجرام/واتساب، بريد | دليل واحد يكفي للربط |
| **ضعيف** — قابل للانتحال أو النسخ | رقم المرسل، اسم المرسل، قالب النص، مسار الرابط | **دليل واحد لا يربط أبدًا.** نوعان مستقلان بقوة مجتمعة ≥ 0.70 ⇒ ربط «مُعزَّز» بثقة منخفضة |
| **لا يربط مطلقًا** | نطاقات المختصِرات والمنصات العامة، النطاقات الرسمية، لاحقات الاستضافة المشتركة (`web.app`…) | مُعلَّمة `linkable=false` عند الاستخراج |

ضمانات إضافية: **نافذة صلاحية** لكل نوع مورد (الأرقام يُعاد تخصيصها) · **كبح المورد الشائع في الرسائل السليمة** (≥3 رسائل سليمة وأغلبية) · **كشف نقطة الربط الوحيدة** (مورد لو أُزيل انقسمت الحملة) يخفض الثقة ويظهر للمحلل · النصوص المتطابقة ببنية مختلفة تبقى حملات منفصلة مع علاقة `same_template_different_infrastructure` · **عائلات القوالب** كيان فرضي مستقل للنص المتكرر.

ثقة الحملة: **مرتفعة** (موردان قويان مشتركان فأكثر بلا نقطة ربط وحيدة) · **متوسطة** (مورد واحد أو جسر) · **منخفضة** (إشارات ضعيفة معزَّزة فقط).

## 3.6 الـAPI

| المسار | الوظيفة |
|---|---|
| `POST /v1/analyze` | تحليل رسالة دون تخزين |
| `POST /v1/messages` | إدخال دفعة (≤500): تحليل، تنقيح، تخزين، ربط |
| `GET /v1/messages[/{id}]` · `DELETE` | استعراض مع التفسير · محو |
| `GET /v1/campaigns[/{id}]` | الحملات وسردها |
| `GET /v1/campaigns/{id}/stix` | حزمة STIX 2.1 لـMISP/OpenCTI |
| `GET /v1/links/explain?a=&b=` | سلسلة الأدلة بين رسالتين |
| `GET /v1/indicators/lookup` | هل شوهد هذا المؤشر؟ في أي حملة؟ |
| `GET /v1/template-families` · `/v1/graph` · `/v1/stats` · `/v1/overview` | عائلات القوالب · رسم الأدلة (مباشر/مستنتج) · إحصاءات · ملخص تنفيذي |
| `GET /v1/indicators` · `/v1/indicators/detail` · `/v1/entities` | مستكشف المؤشرات المجمّعة · ملف مؤشر وعلاقاته · الجهات المنتحلة |
| `GET/POST/PATCH /v1/investigations` | تتبّع التحقيقات على الحملات |
| `GET /v1/db/overview` · `/v1/db/schema` · `/v1/db/tables/{t}/rows[/{rowid}]` | مستكشف قاعدة البيانات — **للقراءة فقط**، مقيَّد بالحساب، جداول مسموحة فقط |
| `GET /v1/system/health` | قياس فعلي لحالة المحرك والقاعدة وخط الربط والواجهة وموارد العملية |
| `POST /v1/retention/purge` | حذف الأقدم من N يومًا |

مصادقة بمفتاح `X-API-Key` يُقابَل بمستأجر؛ لا مفتاح افتراضيًّا (يُولَّد عشوائيًا إن لم يُضبط). مخطط OpenAPI على `/docs`.

## 3.7 قاعدة البيانات (المخطط v2)

| الجدول | المحتوى |
|---|---|
| `messages` | النص **منقّحًا**، الحكم، اللهجة، التحليل الكامل (JSON)، ومصدر البيانات `source` |
| `indicators` | كل مؤشر مستخرج ودوره وقابليته للربط |
| `investigations` | تحقيقات المحللين على الحملات |
| `operations` | سجل عمليات النظام (للمراقبة) |
| `audit` | الإجراءات الحساسة: التصدير والحذف والتحقيقات |

العلاقات **منطقية**: تفرضها طبقة التخزين، ولا توجد مفاتيح أجنبية مُعلنة في SQLite، ويتحقق منها فحص السلامة. الحملات وعائلات القوالب **عروض مشتقة** تُحسب من المؤشرات ولا تُخزَّن. قواعد v1 تُرقّى تلقائيًا عند الفتح.

## 3.8 مسار التوسّع إلى الإنتاج (لم يُنفَّذ)

| الحالي | الإنتاج |
|---|---|
| SQLite، إعادة بناء الرسم عند كل تغيير (0.02 ث لألف رسالة) | Postgres + اتحاد‑بحث تزايدي؛ مخزن رسوم عند تجاوز ~10⁶ رسالة |
| جدول لواحق مضمَّن | قائمة Public Suffix كاملة (`psl.load_suffix_file`) |
| إثراء المؤشرات: لا شيء | إثراء **سلبي** فقط (WHOIS، شفافية الشهادات، قوائم سمعة) كأدلة إضافية؛ لا جلب للروابط |
| مفتاح API | OIDC + أدوار + سجل تدقيق غير قابل للتعديل |
| سجل علامات بذرة | سجل مُدار مع أصحاب العلامات |
