# 5. الأمن والخصوصية

## الخصوصية بالتصميم

| البيان | المعالجة |
|---|---|
| رقم المستلم (الضحية) | لا يُخزَّن. يُستبدل بمعرّف HMAC‑SHA256 بمفتاح (`RASD_PSEUDONYM_KEY`) يسمح بعدّ تكرار الاستهداف دون معرفة المستهدَف |
| أرقام البطاقات (تحقق Luhn)، أرقام الهوية، رموز التحقق في المتن | تُطمس قبل التخزين، **مع حفظ الطول** كي تبقى مواضع الأدلة صحيحة |
| مؤشرات المهاجم (نطاق، رقم تواصل، آيبان مستفيد) | تُحفظ صريحة — هي المادة الاستخباراتية |
| `/v1/analyze` | لا يخزّن شيئًا |
| الاحتفاظ والمحو | `POST /v1/retention/purge` و`DELETE /v1/messages/{id}`، مع قيد في جدول التدقيق |
| العزل | كل استعلام مقيَّد بالمستأجر المشتق من المفتاح (مُختبَر) |

**حدود معلنة:** الأسماء الشخصية داخل المتن لا تُطمس. رقم المرسل قد يكون منتحَلًا ويعود لبريء — لذلك يُعدّ دليلًا ضعيفًا لا يربط وحده، ويُعلَّم بدور «مرسل». قبل أي تشغيل إنتاجي تلزم مراجعة قانونية وفق نظام حماية البيانات الشخصية السعودي وما يقابله في كل سوق؛ هذه الوثيقة ليست رأيًا قانونيًا.

## سلامة التشغيل

- **لا تفاعل مع بنية المهاجم:** لا جلب روابط، لا استعلام DNS، لا اتصال بأرقام. التحليل معجمي بحت.
- **اللوحة تعامل كل نص رسالة كمدخل عدائي:** كل إدراج يمرّ بدالة تهريب، والمؤشرات تُعرض نصًّا لا روابط قابلة للنقر. اختبار المتصفح حقن `<img onerror>` ولم يُنفَّذ.
- **حدود المدخلات:** 5,000 حرف للرسالة، 500 رسالة للدفعة، نمط مقيَّد للمعرّفات.
- **لا أسرار افتراضية:** لا مفتاح API ثابتًا؛ المقارنة بزمن ثابت.

## نموذج التهديد للنظام نفسه

| التهديد | الوضع |
|---|---|
| تسميم الربط: مهاجم يضمّن رقم جهة بريئة ليُنسب إليها | مخفَّف جزئيًا: كبح المورد الشائع في الرسائل السليمة + إظهار نقطة الربط الوحيدة + القرار للمحلل. **لا حجب آليًّا.** |
| التهرب بإضافة عبارة حميدة («لا تشارك الرمز») | الدليل السلبي يُلغى بوجود رابط غير رسمي أو وسيلة تواصل أو طلب بيانات |
| التهرب بالتمويه الإملائي | تطبيع + التمويه نفسه دليل. العربيزي والصور **غير مغطّاة** |
| إغراق البلاغات لإخفاء حملة أو اختلاقها | غير معالَج بعد (يلزم ترجيح مصدر البلاغ) |
| سجل علامات خاطئ يبرّئ نطاقًا خبيثًا | خطر حقيقي: السجل بذرة ويجب أن يُدار مع أصحاب العلامات |
| حقن تعليمات عبر نص الرسالة في نموذج لغوي | غير منطبق افتراضيًا (لا LLM)؛ وإن أُضيف فمساهمته مسقوفة ولا تُدين |
